# India CTC → in-hand reference

> **Verify before use.** The values below are for **FY 2025-26 (AY 2026-27), new tax regime**, from Budget 2025. Slabs, rebate and standard deduction can change in every Union Budget. If a web tool is available, confirm the current year's numbers first. If you use these values for a different year, say so.

## Typical components
| Component | Typical value | In-hand? |
|---|---|---|
| Basic | 35–50% of fixed | Yes |
| HRA | 40–50% of basic | Yes (taxable under the new regime) |
| Special / flexi allowance | Balancing figure | Yes |
| Employer PF | 12% of basic, often capped at 12% of ₹15,000 = ₹1,800/month | No (goes to the PF account) |
| Employee PF | Same as employer, deducted from salary | Deducted |
| Gratuity | ≈ 4.81% of basic | No (paid only after 5 years of service) |
| Insurance premium | Varies | No |
| Variable / performance bonus | % of CTC | Paid annually/quarterly if earned |
| Joining bonus | One-time | Yes, once (often with a clawback) |

## New regime, FY 2025-26
- Standard deduction (salaried): **₹75,000**
- Slabs on taxable income:

| Income | Rate |
|---|---|
| 0 – 4,00,000 | 0% |
| 4,00,001 – 8,00,000 | 5% |
| 8,00,001 – 12,00,000 | 10% |
| 12,00,001 – 16,00,000 | 15% |
| 16,00,001 – 20,00,000 | 20% |
| 20,00,001 – 24,00,000 | 25% |
| Above 24,00,000 | 30% |

- Section 87A rebate: tax is nil if taxable income ≤ **₹12,00,000** (so gross salary up to ₹12.75 L after the standard deduction). Marginal relief applies just above this threshold.
- Health and education cess: **4%** on the tax.
- Surcharge applies above ₹50 L taxable income (rare for freshers; mention it if relevant).
- The old regime (with 80C, HRA exemption, etc.) can be better for people with large deductions, such as high rent in a metro. Mention it as an option, but compute the new regime by default.

## Other deductions
- Professional tax: up to **₹2,500/year**, state-dependent (e.g. Karnataka, Maharashtra, West Bengal, Telangana levy it; Delhi does not).
- Employee PF: 12% of basic, or the capped ₹1,800/month, per the offer letter. Ask if unclear.

## Method
1. Gross taxable salary = fixed cash + variable actually received (+ joining bonus in the year received). Employer PF within limits is not taxable salary.
2. Taxable income = gross − standard deduction.
3. Tax = slab tax → apply the 87A rebate/marginal relief → + 4% cess.
4. Annual in-hand = gross − tax − employee PF − professional tax.
5. Monthly in-hand: compute on **fixed pay only** (variable usually pays out later), spreading the annual tax on fixed pay over 12 months. Show the variable payout separately.
